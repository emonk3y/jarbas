Privacy policy

Jarbas is a private family assistant run by one household on its own server. It is not available to anyone else.

Google data

  • With the account holder's consent, Jarbas reads and creates/changes events in the Google Calendars that were explicitly shared with it, to answer the household's questions and add events they approve.
  • It requests only calendar event access. It does not access email, contacts, files or any other Google data.
  • Calendar data is processed on the household's own server and is not sold, shared with third parties or used for advertising. Event details may be sent to an AI model provider only to answer a household member's request, under terms that exclude training.
  • Access can be revoked at any time at myaccount.google.com/connections or by unsharing the calendar.

Jarbas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
